# decodelabs-data-cleaning-project1
Data Cleaning and Preparation project completed during my Data Analytics internship at DecodeLabs.
## Objective

Clean and prepare a raw dataset by:

- Handling missing values
- Checking duplicate records
- Standardizing text values
- Correcting date and numerical formats
- Verifying unique identifiers
- Validating total price calculations

## Tools

- Python
- Pandas
- NumPy
- Google Colab
- Microsoft Excel

## Final Results

- Records: 1,200
- Columns: 14
- Missing values: 0
- Duplicate rows: 0
- Duplicate Order IDs: 0
- Duplicate tracking numbers: 0
- Invalid dates: 0
- Incorrect total prices: 0
